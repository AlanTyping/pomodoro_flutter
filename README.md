# ⏱️ Pomodoro Challenge

Un Pomodoro app construido con Flutter, aplicando buenas prácticas en equipo.  
Rápido, ordenado y pensado para escalar.

---

## 🧱 Stack & Arquitectura

- **Flutter + Bloc** para gestión de estado predecible.  
- **Clean Architecture** con organización *feature-first* para mantener módulos desacoplados.  
- **SQLite** como base de datos local para persistencia offline.  

---

## 🎯 Objetivos del proyecto

- Practicar arquitectura limpia aplicándola a un caso real.  
- Mantener un código fácil de testear y extender.  
- Crear una experiencia Pomodoro fluida y sin distracciones.
